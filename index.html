Groblje Petrijevci

Karta koristi Googleovu satelitsku snimku, za koju treba vlastiti Google Maps API ključ (besplatno do 10.000 učitavanja karte mjesečno, ali Google traži da je naplata uključena).

  1. Otvorite console.cloud.google.com/google/maps-apis i prijavite se.
  2. Napravite projekt i uključite naplatu (billing).
  3. Uključite Maps JavaScript API.
  4. Pod „Keys & Credentials“ napravite API ključ i kopirajte ga ovdje.
  5. Ako stranicu stavite na internet, u postavkama ključa ograničite ga na adresu stranice (HTTP referrers).

Ključ se sprema samo u ovom pregledniku.
